# Devin Hacks Kochi: lxask slides

Track 3, "Works Anyway". lxask is an offline Linux-command assistant: a 1.5B-parameter model that runs on a CPU
with no internet, no account and no API key, and checks every command against the man pages and tldr.

- `lxask-hackathon.pptx`: 8 slides with speaker notes (editable)
- `lxask-hackathon.pdf`: the same slides as a backup

The project began on 2026-10-12; this repository is a fresh-history copy (see the main README). Benchmark
numbers on the slides come from [docs/accuracy.md](../docs/accuracy.md).
